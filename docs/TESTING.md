# 测试策略

## 分层

- `单元测试`：调度规则、停止条件、记忆作用范围和消息安全规则。
- `集成测试`：SQLite 与 PostgreSQL 迁移、空账号初始化、入门资料、激活事件幂等、原子限流、账号工作区隔离、会话过期与撤销、购买申请、30 天权益、10 人名额上限、数据库事务、幂等记录和设置更新；后续覆盖队列和渠道适配器。
- `冒烟测试`：注册、空工作区、入门流程、登录、认证限流、退出、未授权 API、跨账号隔离、今日队列、确认追问、添加机会、设置更新、购买申请、管理员确认收款、权益生效和重载持久化。
- `AI 行为评测`：承诺日期提取、缺失信息追问、禁止编造和停止追问。

## Pull Request 必跑

1. ESLint
2. TypeScript 类型检查
3. 单元测试与覆盖率阈值
4. Next.js 生产构建
5. Chromium 核心冒烟测试

领域模块的最低覆盖率为：行、函数和语句 85%，分支 80%。覆盖率不能替代关键场景断言。

## 发布前冒烟清单

- 注册、登录、退出、会话重载和租户隔离正常。
- 新账号没有演示机会；入门资料重载后仍然存在。
- 完成入门后会连续引导添加第一个真实机会。
- 注册到首次确认追问的激活事件不会因重试重复计数。
- 普通账号不能读取运营申请或确认收款；未登录返回 401，非管理员返回 403。
- 购买申请不会自动开通权益；管理员确认收款后准确生成 30 天起止时间。
- 重复申请、重复确认不重复计数或延长权益；第 11 位确认被服务端拒绝。
- 同一邮箱连续错误登录超过阈值后返回 429 和 `Retry-After`。
- 未登录请求返回 401，跨账号记录不能读取或修改。
- 能创建机会并生成合理的下一次追问时间。
- 用户能编辑和确认草稿。
- 新机会和设置在页面重载后仍然存在。
- 相同任务重复执行不会重复发送。
- 招聘方回复后计划任务取消。
- 拒绝、关闭和放弃状态不会产生新任务。
- 桌面端和移动端无内容遮挡或横向溢出。
- 健康检查、日志、告警和回滚版本可用。

## AI 回归样例

| 输入 | 必须行为 |
| --- | --- |
| “这周讨论一下，有结果联系你” | 下一个工作日再跟进，不立即发送 |
| “岗位已经停止招聘” | 关闭机会并取消全部追问 |
| “你的最低薪资是多少？” | 没有已确认信息时先询问用户 |
| “再等等吧” | 询问或使用明确日期，不能无限循环 |

AI 评测输出应保存模型、提示词版本和测试数据版本，避免只比较自然语言字面结果。

## PostgreSQL 方言验证

测试使用 PGlite 执行真实 PostgreSQL SQL，而不是把 `pg` 查询完全 Mock 掉。覆盖 TIMESTAMPTZ、JSONB、布尔类型、表达式唯一索引、外键、事务、`FOR UPDATE` 和可重复读快照。部署到托管 PostgreSQL 前仍应在预发布环境执行迁移和核心冒烟测试。
